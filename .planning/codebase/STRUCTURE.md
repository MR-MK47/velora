# Codebase Structure

**Analysis Date:** 2026-06-08

## Directory Layout

```
velora/
├── .agent/              # OpenGSD skill directories, config hooks, and agents
├── .planning/           # Project roadmap, plans, and codebase mappings
│   └── codebase/        # Mapped codebase documents
├── dist/                # Production build artifacts (compiled output)
├── node_modules/        # Vendor packages and dependencies
├── src/                 # Application source code
│   ├── components/      # Reusable visual components and modals
│   ├── layouts/         # Shared views frame structure (sidebars, overlays)
│   ├── lib/             # Shared libraries and utility folders
│   └── pages/           # High-level route pages (Landing, Login, Dashboard, Settings)
├── .env.example         # System environment variables sample
├── index.html           # Application root HTML page
├── package.json         # Dependency configuration and build scripts
└── tsconfig.json        # TypeScript compiler options
```

## Directory Purposes

**src/components/**
- Purpose: Host shared reusable components and interactive widgets
- Contains: `*.tsx` React component files
- Key files: `ExtractionModal.tsx` - Handles clip parsing link submissions

**src/layouts/**
- Purpose: Frame layout layouts wrapping specific pages
- Contains: `*.tsx` files
- Key files: `DashboardLayout.tsx` - Admin sidebar console wrapper

**src/lib/**
- Purpose: Helper utilities and libraries
- Contains: `*.ts` configuration helpers
- Key files: `utils.ts` - Conditionally joins Tailwind styles

**src/pages/**
- Purpose: Root page layouts rendered inside routing switches
- Contains: `*.tsx` files
- Key files:
  - `Landing.tsx` - Landing page layout
  - `CommandDashboard.tsx` - Data analytics screen
  - `CampaignWorkspace.tsx` - Campaign workspace page
  - `Settings.tsx` - Local preferences page

## Key File Locations

**Entry Points:**
- `src/main.tsx` - Mounts React components tree
- `index.html` - App launch template

**Configuration:**
- `package.json` - Declares scripts and libraries
- `tsconfig.json` - Declares TypeScript compiler parameters
- `vite.config.ts` - Configures Vite build compiler
- `.env.example` - Declares environment variables required

**Core Logic:**
- `src/App.tsx` - Implements route layouts switcher

**Testing:**
- No test files present in this codebase yet

**Documentation:**
- `README.md` - Getting started instructions
- `Velora_Master_Plan.md` - Original build blueprint and master brief document

## Naming Conventions

**Files:**
- `PascalCase.tsx` - For React UI components and pages (e.g. `CommandDashboard.tsx`, `ExtractionModal.tsx`)
- `camelCase.ts` - For helper libraries (e.g. `utils.ts`)
- `kebab-case` - Standard for non-source files (e.g. `package-lock.json`, `.env.example`)

**Directories:**
- `kebab-case` - For project folders (e.g. `node_modules`, `velora-worker`)
- Plural nouns for source containers (e.g. `components`, `layouts`, `pages`)

## Where to Add New Code

**New Page/Route:**
- Implementation: `src/pages/[PageName].tsx`
- Registration: Add lazy import and router path in `src/App.tsx`

**New Reusable Component:**
- Implementation: `src/components/[ComponentName].tsx`

**New Utility Helper:**
- Implementation: Add to `src/lib/` or update `src/lib/utils.ts`

## Special Directories

**dist/**
- Purpose: Bundled production compiled output
- Source: Generated by running `npm run build`
- Committed: No (listed in `.gitignore`)

**.planning/**
- Purpose: GSD workflow task states, plans, roadmap, and mapped codebase specifications
- Source: Created and managed by GSD tools / agents
- Committed: Yes (source of truth for project planning state)
